type: minor

El coordinador fusiona por el merge gobernado del repo (`runner-merge.yml` o `governed-merge.yml`) cuando existe, y nunca con `gh pr merge`. Si el workflow bloquea la PR, corrige lo que nombra el hallazgo y lo relanza. `gh pr merge` queda solo para los repos sin ese workflow. Así el contrato del host, `merge_freshness` incluido, se aplica también a las PRs que fusiona el orquestador.
