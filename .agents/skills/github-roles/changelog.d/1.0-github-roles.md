Skill nueva `github-roles`: los roles de GitHub de las IAs. El colaborador (`dys-agentes`) abre issues, empuja ramas y abre PRs, pero **no fusiona**; el coordinador (`dys-orquestador`) puede hacerlo o delegar, y al delegar pasa **siempre** la identidad de colaborador, nunca la suya. Sin rol dicho, la IA es colaborador, y la cuenta personal del dueño no se usa nunca (#1095).
